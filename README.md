# Prakash Varu — Unreal Engine Portfolio Site

A web-based interactive replica of the **Unreal Engine 5.4 Editor** showcasing Prakash Varu's career, shipped games, digital twin solutions, gameplay systems, and Unreal Engine development work.

The portfolio is designed to feel like working inside the Unreal Editor, featuring an **Outliner, Content Browser, Blueprint/Event Graph, Details panel, Output Log, viewport controls, and editor-style performance stats.**

## Live Site

**[Open Portfolio](https://prakashvaruunrealeditorportfolio.vercel.app/)**

## Features

* Unreal Engine 5.4 inspired interface
* Interactive Editor-style viewport
* Outliner and Content Browser
* Blueprint / Event Graph interface
* Experience, Itch.io, and YouTube sections
* Unreal Engine, C++, and gameplay development showcase
* Editor-style FPS and performance stats
* Developer console with commands
* Keyboard shortcuts and interactive controls

## Run Locally

### Option 1: PowerShell Server (No dependencies required)

Run:

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```

Open **http://localhost:5173/** in your browser.

### Option 2: Vite (If Node.js is installed)

```bash
npm install
npm run dev
```

### Option 3: Direct File

You can also open `index.html` directly in any modern web browser.
