# Prakash Varu — Unreal Engine Portfolio Site

A web-based interactive replica of the **Unreal Engine 5 Editor (5.4 / 5.5)** showcasing Prakash Varu's career, shipped games, digital twin solutions, and gameplay systems engineering.

## Run Locally

### Option 1: PowerShell Server (No dependencies required)
Run:
```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1
```
Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.

### Option 2: Vite (If Node.js is installed)
```bash
npm install
npm run dev
```

### Option 3: Direct File
You can also open `index.html` directly in any modern web browser.
